## 手机 Agent MVP（v0.20.0，02:40–03:10）

- **agent/ 六件套**（照抄方案 = Aries-AI 蓝图 + DroidRun 控件编号 + AppAgent prompt + Operit 围栏思路）：
  - `AgentAccessibilityService`：单例 instance + windowTick（窗口变化计数）+ TYPE_ACCESSIBILITY_OVERLAY 悬浮「■ 停止」（无障碍服务加 overlay 免权限）。
  - `ScreenState`：控件树 BFS → 编号清单（上限 40 元素/600 节点，visible 且 clickable/editable/scrollable/有文本），toPrompt 纯函数单测。
  - `AgentPrompts`：五动作 JSON 协议（tap/text/swipe/back/done）+ 宽容解析（截取首{末}，缺 action 返 null）+ isSensitive 敏感词表（支付/删除/发送…）。
  - `AgentLoop`：观察→LLM（复用 OpenAiClient）→执行→等界面稳定（windowTick 安静 900ms 或超时 2.5s）；解析失败重试 1 次；**连续相同动作 2 次判卡住**；白名单围栏在每步开头检查 currentPackage。
  - `ActionExecutor`：dispatchGesture（tap 120ms/swipe 300ms）+ ACTION_SET_TEXT（按 bounds 中心找回节点，非 editable 向子节点找）+ GLOBAL_ACTION back/home。
  - `AgentConfig`（DataStore 存 SettingsRepository）：maxSteps=15、白名单（**空 = 不限制，非空 = 仅清单内，本应用永远放行**）、sensitiveConfirm=true。
- **UI**：任务页顶栏 ▶（MIcons.Play 新增）→ AgentSheet：Idle（目标/白名单/确认开关/无障碍引导）→ Running（日志流 + 敏感确认内联 + 停止）→ Finished（摘要「写入会话」= TasksViewModel.writeAgentSummary 写主导师会话）。
- **坑**：① suspend 函数表达式体（`= when`）里不能 return → 改块体；② 扩展函数不能全限定调用（同 Glance updateAll）；③ 服务 enabled 判断用 Settings.Secure ENABLED_ACCESSIBILITY_SERVICES 前缀匹配。
- 验证：51/51 测试绿（+7 AgentLogicTest）；aapt2 badging `provides-component:'accessibility'`；dex 抽查 AgentAccessibilityService 原名保留；真机待验（需在系统设置开启无障碍服务）。
