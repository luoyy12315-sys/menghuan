## 完成明细

1. **消息滚动**：首帧 `scrollToItem`（不进聊天时的 `animateScrollToItem` 会从 0 滑到最后，长会话进页面肉眼可见地横冲直撞 = 用户报的闪烁）。会话列表同样 `scrollToItem(0)`。

3. **暗色模式**（本次最大工程量）：见下方「深色模式改造」。
4. **人设渐变环随机化**：`personaPaletteOf(id)` = `(id * 2654435761L) and 0x7FFFFFFF` 散列 → 12 组品牌配色 × 2 走向，`sweepGradient`。稳定（重启不变）、负 id 与 Long.MAX_VALUE 不崩。
5. **闪烁修复**：除了首帧滚动，还补了 `values-night` 冷启动底色 + 主题首帧同步读（`themeModeBlocking()`，否则先亮后暗再闪）。

### 深色模式改造（本次最需要记住的部分）
- 颜色令牌从"写死的 top-level val"改成 `NeuPalette` data class + `LocalNeuPalette`，
  对外暴露同名的 `@ReadOnlyComposable` getter（`NeuBackground` / `TextPrimary` / `NeuAccent` …），**调用点一行没改**。
- 新增 `AccentInk`（强调色上的文字/图标）：强调色从黑反相成白，这个 token 跟着翻，
  否则深色下用户气泡白底白字。这是"反相式"配色最容易漏的一处。
- 全 App 裸 `Color.Black/White/0xFFE0E0E0` 等 **40 处**逐个换令牌（含 `DropdownMenu`/`AlertDialog`/`DatePicker` 的 containerColor）。
- **令牌只能在 composable 里读**：`drawBehind`/`Canvas` 的 DrawScope 不是 composable，
  必须先 `val ink = NeuAccent` 取局部值再传进 lambda。`inline()`（MarkdownText）、
  `highlight()`（ChatListScreen）两个纯函数因此都加了颜色参数。
- `neuSurface` / `figmaSelection` 改成 `@Composable`：把令牌读出来当参数传给 drawBehind。
- 资源：`values-night/colors.xml`（深冷启动底色）+ `values-night/themes.xml` +
  `values-night-v29/themes.xml`（Force Dark 仍然关）。**`values-v29-night` 是非法目录名**，
  AGP 报 `Invalid resource directory name`，正确是 `values-night-v29`。
- `MentorThemedRoot`：解析「模式 + 系统深色」→ `MentorTheme(darkTheme=)`，
  并在 `SideEffect` 里同步 `enableEdgeToEdge` 的 `SystemBarStyle`（深色下图标翻白）。
  首帧用 `settingsRepository.themeModeBlocking()` 同步取值（`cachedThemeMode` 内存缓存兜底二次读）。
- `ThemeMode.fromName` / `resolveDarkTheme` 是纯函数，单测覆盖。

## 踩坑
- **大 payload 的 edit 工具调用会静默丢掉 `path` 参数**（报 "Missing key: path"）——
  改动大就拆成几次小 edit。
- `@ReadOnlyComposable` 里不能调 `remember`（Brush getter 原本带 remember，得去掉 `@ReadOnlyComposable`）。
- `SystemBarStyle.dark(scrim)` 只有**一个**参数（`light` 才有两个）。
- `ChatViewModel` KDoc 里"对话风格按 persona 持久化（长按头像切换）"是 v0.20.1 的遗留，已改。
- **`EmojiPack.isPureEmoji` 要跳过空白**：用户粘过来的表情常带前后空格，
  原实现遇到空格直接 return false（V035LogicTest 抓到）。
- 测试同步：`ChatViewModelTest` 构造加 `app.filesDir`；`UiRenderTest.render2Data/render7DataReal`
  与 `UiRenderTabletTest.tablet2DataWide` 断言从「档案种子（自由职业）」改成新合并卡文案
  （档案已移出数据页）；新增 `render14DarkMode` 截图。

### 踩坑
- 删 EmojiPanel 时用 PowerShell 按字符串切片删除，漏掉了紧邻的 `import LazyRow` 和
  `EmojiPack`（`$s.Replace` 的换行符是 `\r\n`，文件里也是，一并删掉了才干净）。
  教训：批量删代码后**必须再 grep 一次残留引用**，我这次漏了两轮编译才发现。
- 服务器重启后 `subst X:` 映射会消失（AGENTS 坑之五同源），直接 `Set-Location X:\` 会报
  DriveNotFound，重新 `subst X: "<项目路径>"` 即可。
- `NeuTextButton(text, onClick)` 的 `color` 是**第三个**参数且有默认值，
  想改色必须写 `NeuTextButton("x", onClick = {...}, color = NeuDanger)` —— 写成
  `NeuTextButton("x", color = ...)` 会报 "No value passed for parameter 'onClick'"。
