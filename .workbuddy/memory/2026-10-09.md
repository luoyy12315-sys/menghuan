## v0.75.0（versionCode 164）· 紧急修复 v0.74.0 覆盖安装闪退

### 现象
用户反馈：装上 v0.74.0 后「一进页面就闪退」，且**原数据看起来全没了**。

### 根因（用户截图 CrashLog 一击确诊）
```
IllegalStateException: Migration didn't properly handle: interaction_bindings
Expected: ... primaryKeyPosition=2, indices=[]
Found:    ... indices=[Index(name='index_interaction_bindings_actionId', ...)]
```
`MIGRATION_22_23` 里建了索引 `index_interaction_bindings_actionId`，
但 `InteractionBindingEntity` **没声明这个索引**（`indices=[]`）。
Room 在 `onUpgrade → onValidateSchema` 逐项比对索引列表 → 多一个 → 抛异常。
出错在**打开数据库**那一刻，所以表现是"进页面就崩"，且所有列表读不到数据显示为空。

### 修复
`data/model/Live2dActions.kt` 给 `InteractionBindingEntity` 补：
```kotlin
indices = [Index(value = ["actionId"], name = "index_interaction_bindings_actionId")]
```
schema 23.json identityHash：`fab82c7141…` → `40463c3bc8…`。

### 数据没丢（已用真实 SQLite 实测）
Room 升级走 SQLiteOpenHelper 事务，校验失败 → **整个升级回滚**：
- `user_version` 保持原值
- personas / messages 等存量数据分毫未动
- interaction_bindings 无残留
修复版装上重开 → 迁移重跑成功 → **数据自动回来**。
⚠️ 唯一真丢情形：崩溃后**卸载重装**（App 数据被系统清掉）。

### 补了迁移回归测试（此前一道都没有 —— 这就是漏网原因）

### ① `AiCallLogic.parseWantedCallAt` = **真 bug**（改实现）
