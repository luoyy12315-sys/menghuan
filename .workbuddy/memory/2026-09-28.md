## v0.3.0 收尾补丁：搜索去抖坑（03:40）

- **Robolectric 坑之六**：`viewModelScope.launch { delay(200); ... }` 在 Robolectric PAUSED 主线程时钟下 **delay 永不恢复**（任务挂在 Scheduler 上等虚拟时钟推进，compose 测试 idling 不推进它）→ 搜索防抖协程永远停在 delay → 结果永不上屏。UiRenderTest 7-search 初版靠这个抓出来的：DAO 直查命中但 UI 一直"没有匹配结果"，加 println 到测试 system-out 定位到"job start 打了、delay 后的没打"。
- 解法：搜索去掉 delay 防抖，保留 `searchJob?.cancel()` 取消旧任务模式（本地 LIKE 查询毫秒级，无性能顾虑；任何环境行为一致）。
- 最终 recordRoborazziDebug **8 张截图全绿**（新增 7-search：输入"睡前"命中回执消息行）。诊断用 println 已清理。
- 教训：**JVM 截图测试里避免 viewModelScope + delay 的逻辑**（防抖/节流/延迟动画触发），要么走动画 API，要么 cancel-previous。
