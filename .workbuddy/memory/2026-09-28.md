## API Key Keystore 加密迁移（v0.2.3，01:20–01:30）

- 落地 AGENTS §五.4 与路线图最后的安全项：`data/ApiKeyCipher.kt` = AndroidKeyStore 内 AES-256-GCM 密钥（不可导出，alias `daoshi_api_key`），DataStore 只落密文 `api_key_enc` = Base64(IV 12B + GCM 密文)。
- SettingsRepository：读路径密文优先（带"密文不变复用内存明文"的解密缓存，避免每次重组打 Keystore）；读到旧明文 `api_key` 即自动加密搬移并删明文；**回退策略**——Keystore 不可用/加密失败 → 回退读明文且不删（密钥绝不凭空消失，Robolectric JVM 即此路径）；解密失败（锁屏凭据变更致密钥失效）→ 视为空，用户在 API 配置重填。读写全部 Dispatchers.IO。
- 测试：SettingsRepositoryTest（Robolectric，runBlocking）预置旧明文 → 断言迁移读取不丢 → save 后重读闭环；JVM 无 AndroidKeyStore 恰好把回退路径测实。recordRoborazziDebug 回归 5/5 通过（含 4 页截图）。
- 产物：versionCode 7 / versionName 0.2.3，aapt2 badging + apksigner 验证通过，1.57MB，根目录 `导师-v0.2.3-release.apk`（v0.2.2 已删）。
