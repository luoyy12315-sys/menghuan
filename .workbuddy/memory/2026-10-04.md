### 键盘（新文件 `ui/chat/KeyboardInsets.kt`，`rememberBottomBarInset(followKeyboard)`）
- 来源：Google 官方《控制软件键盘并为其添加动画效果》+ `WindowInsetsAnimationCompat`；
  思想借鉴 `DSAppTeam/PanelSwitchHelper`（2.4k star，View 体系已停更 → 只取思想不引库，
  硬套必须重写输入区为 XML = 违背"复用现有 UI"）。
- 根因复盘：旧版三补丁（单调收敛 INSET_SETTLE_MS / 静默期 OUTPUT_SWITCH_QUIET_MS /
  方向性动画）的共同根因 = **navigationBars 被当逐帧实时量**，
  键盘收起必有一帧 `ime=0 && navBar=0` —— 取 max 修不了中间帧。
- 新做法：① navBar 只在 `ime==0` 时刷新**基线**；② 面板/语音态 `followKeyboard=false`
  直接返回基线不读 ime（静默期的替代）；③ ime 优先取官方动画回调逐帧插值、回落 Compose 值；
  `imeComposePx==0` 强制归零 = 自愈保护（防 onEnd 丢失卡死在旧高度）。
- 删掉 ChatScreen ~120 行补丁；`switchOutputMode` 只剩三态互斥 + 键盘显隐。

### 语音采集（`VoiceRecorder` 内部重写，对外 API 不变，ChatScreen 零改动）
- 来源：vosk-android-demo(15.2k)/sherpa-onnx(14.3k)/whisper.cpp(51k) 三家 Android 采集层
  统一做法 = `AudioRecord` 直采 16kHz/MONO/PCM_16BIT + 手拼 44 字节 WAV 头。
- 关键点：构造后必须查 `state==STATE_INITIALIZED`（构造不抛≠拿到麦）；独立抽水线程写文件、
  收尾回填 WAV 头；采样率 16k→44.1k 两条候选；`pumpThread.join()` 完才算录完。
- **本地离线 ASR（vosk/sherpa-onnx 模型）未引入**——需下载 40-80MB 模型+设置项，
  属重大变更，等用户拍板。识别层仍是云端 Whisper 主力，`SpeechToText` 未动。
